Cara mengedit video

Edit langsung di Studio (ala CapCut)

  1. Klik ✂️ Edit video di lembar kerjanya.
  2. Geser klip di timeline untuk memindah waktunya, tarik ujung kiri/kanan untuk memendekkan atau memanjangkan. Tekan S untuk memotong di playhead.
  3. Klik teks atau elemen untuk mengubah isi, posisi, ukuran, warna, dan animasi masuk/keluar. Teks juga bisa diseret naik-turun langsung di layar pratinjau.
  4. Tambah klip, foto, teks, elemen Instagram, dan efek suara dari panel kiri. Semua perubahan tersimpan otomatis.
  5. Klik Ekspor MP4: video dirender di browser (pakai Chrome di laptop, ±3–5 menit), lalu otomatis mengganti video di lembar kerja dan bisa disimpan ke perangkat.

Edit sendiri di Remotion Studio

  1. Unduh repo GitHub PT-Mencari-cinta-sejati, buka folder konten/video-remotion.
  2. Pasang Node.js, lalu jalankan:
    npm i
npm run dev
  3. Remotion Studio terbuka di browser. Klik teks, subtitle, atau klip di timeline untuk mengubah isi dan waktunya.
  4. Render hasilnya:
    npx remotion render JodohOnline out/video.mp4 --license-key=free-license
npx remotion still Cover out/cover.png --license-key=free-license
  5. Unggah file baru lewat tombol Ganti video / Ganti cover di lembar kerjanya.

Minta Claude yang mengerjakan

  1. Tulis revisinya di kolom Catatan revisi untuk Claude pada video yang bersangkutan.
  2. Di chat, bilang: "kerjakan revisi di Studio Konten".
  3. Claude membaca catatan itu, mengedit dan merender ulang, lalu memperbarui video, cover, dan statusnya di sini.
